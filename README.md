# 消了个消 🎮

一款基于网页的堆叠三消小游戏，零外部依赖，移动端优先设计。

## 🎯 游戏玩法

1. 屏幕上有多层堆叠的 Emoji 方块
2. 点击可见的（未被遮挡的）方块，方块进入底部收集槽
3. 收集槽中凑齐 3 个相同图案 → 自动消除
4. 收集槽满 7 格且无法消除 → 游戏失败
5. 场上所有方块全部清空 → 通关

## 🏰 关卡设计

| 关卡 | 图案种类 | 方块总数 | 层数 | 定位 |
|------|---------|--------|------|------|
| 第1关 | 3种 | 12个 | 2层 | 教学 |
| 第2关 | 4种 | 18个 | 2层 | 热身 |
| 第3关 | 5种 | 27个 | 3层 | 入门 |
| 第4关 | 6种 | 36个 | 3层 | 过渡 |
| 第5关 | 8种 | 48个 | 4层 | 💀地狱 |

## 🛠 道具系统

- **撤回**：将最后放入槽位的方块退回原位，每关可用 1 次
- **洗牌**：将场上剩余方块重新随机排列位置，每关可用 1 次

## 🏆 排行榜

- 本地排行榜（localStorage），记录每关的通关时间
- 在关卡选择页面显示每关的最佳通关时间

## 🚀 如何运行

直接用浏览器打开 `index.html` 即可运行，无需服务器。

或使用任意本地服务器：
```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

## 📱 技术特点

- 纯 HTML + CSS + JavaScript，零外部依赖
- 移动端优先适配（响应式设计）
- 方块堆叠采用绝对定位 + 层偏移实现
- 被遮挡方块半透明且不可点击
- 方块飞入槽位动画
- 三消闪烁消除动画
- UI 风格：圆角卡片、柔和配色、现代简约

## 📝 设计说明

### 堆叠逻辑
- 每个关卡的方块分布在网格区域中
- 多层方块通过偏移 (offset) 产生层叠效果
- 上层方块遮挡下层：重叠面积 > 30% 即判定为遮挡
- 被遮挡方块显示半透明 + 灰色遮罩

### 可解性保证
- 每种图案数量严格为 3 的倍数
- 方块总数为 3 的倍数
- 道具（撤回 + 洗牌）提供容错空间
